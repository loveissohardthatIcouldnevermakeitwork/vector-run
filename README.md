# Vector Run Tracker

A sci-fi running app for building a steady running habit. It runs in the phone's browser and installs to the home screen like an app.

**Open the app:** https://loveissohardthaticouldnevermakeitwork.github.io/vector-run/

## Install on Android
1. Open the link above in Chrome.
2. Tap the ⋮ menu, then **Install app** (or **Add to Home screen**).
3. Open Vector from the home screen and allow location when asked.

## What it does
- **Run:** GPS tracking, a pace dial that recommends a pace from your recent runs and tells you to ease off or pick it up, voice cues, and four run types: free, distance, time, and run/walk intervals.
- **Log:** every run with its route, per-km splits and a pacing note.
- **Debrief:** weekly goal and streak, distance per week, pace trend, and a suggestion for the next run.
- **Train:** warm-up, strength and cool-down routines, plus healthy running habits.
- **Finish animation** after every run.

The run log is stored on the phone only. Use **Log → Copy backup** now and then.
